# COC-Stats

A responsive, single-page **Clash of Clans fan website** with a hero section, an about section, and quick links to clans, town halls and troops on the official wiki.

🔗 **Live site:** https://predaking07.github.io/COC-Stats/

## Features
- A responsive layout with a hamburger menu on small screens
- Scroll-reveal animations (ScrollReveal.js)
- Icons from Boxicons and Remix Icon, with Google Fonts typography

## Tech stack
HTML · CSS · JavaScript · ScrollReveal.js

## Run locally
Clone the repo and open `index.html` in a browser. It's a static site, so it needs no build step.

*An early front-end project (2023), built while learning HTML, CSS and JavaScript.*
